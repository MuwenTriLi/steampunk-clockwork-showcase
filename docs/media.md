Only presentation copies were created. Source models, images, videos and folder organization were left unchanged. The still frames retain the source camera composition and appearance. The two gray-shaded motion studies use a centered square crop to reduce empty borders. No retouching, relighting or generated content was applied. GIF conversion reduces resolution, frame rate and color precision for web viewing. The MP4 viewing copy omits audio.

The media documents existing work and does not establish a new technical validation of the original Blender package.
